# AI Course Recommendation Agent

## Description
An AI-powered application that recommends a personalized learning path based on a student's background, skills, and career goals.

## Technologies Used
- Python
- Streamlit
- Groq API
- Llama 3.3 70B
- JSON

## Features
- Personalized learning paths
- AI-generated recommendations
- Simple Streamlit interface
- Course catalog in JSON
- Groq LLM integration

## Installation

1. Clone the repository

```bash
git clone <repository-url>
cd Course-Recommendation-Agent
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Create a .env file

```text
GROQ_API_KEY=YOUR_API_KEY
```

4. Run the application

```bash
streamlit run app.py
```

## Project Structure

- app.py
- recommender.py
- courses.json
- sample_profiles.json
